# Omniball 0.3.0 preview — testing guide

This is a development preview for evaluating the fixes and new UI. It has not been submitted to Google Play.

## Install the Android preview

1. Copy `Resuvika-Omniball-Android-0.3.0-PREVIEW.apk` to a physical Android phone and install it.
2. Open **Omniball Preview**. It installs alongside the existing app, using the separate package `com.vikashya.resuvika.omniball.mobile.preview`. Existing app data is not migrated or replaced.
3. The four bottom destinations are **Board**, **Notes**, **Documents**, and **Connect**. The grid button in the upper right opens saved boards. The pen button opens drawing tools.
4. Swipe across the bottom navigation to switch destinations. Drawing gestures on the board stay drawing gestures. Lists, settings, and PDF pages scroll normally.

## PDF and Back

- Documents → Import PDF → choose a file up to 25 MB. PDFs are retained privately on this device.
- Use the page arrows and zoom controls. “Read page text” exposes extractable text. Scanned pages without text need OCR, which this preview does not provide.
- The visible Documents Back button, Android Back, and keyboard Escape return to the document library. Back from another main destination returns to Board; Back at Board minimizes the app.
- Notes → PDF opens a note preview. Print / Save as PDF uses Android’s print sheet, keeping the app’s own page intact.
- Password-protected PDFs show an explanation; import an unlocked copy for this preview.

## Bluetooth with your Windows laptop

1. On Windows, start `Omniball-Windows-Companion-Preview.exe` from a folder you can write to. Open the local viewer URL shown in its window. Keep that window running.
2. Pair the laptop and phone in Android / Windows Bluetooth settings.
3. On the phone: Connect → Choose paired device → allow Nearby devices → select the laptop.
4. **Send board & notes** transfers a complete backup. Enable **Live drawing** to show the phone’s board and notes on the laptop. Completed marks and in-progress pen/shape previews are sent.
5. To send a PDF from the phone, open it in Documents → Send to device.
6. On the laptop, use **Send to your phone** to choose and send a file. Incoming phone files appear under Connect → Received files. Open a received board or save/share a received file there.
7. Laptop files are saved beside the companion executable in `Omniball_Received`. Existing files are not overwritten. Received files are not opened automatically.
8. Both devices confirm completed file receipt after verifying the file digest. Stay in Omniball on Android during a session; leaving the foreground ends the Bluetooth link. Reconnect when returning.

The Windows companion receives live drawings; it is not a second full drawing editor. Its preview approximates some advanced shape styles. A complete board backup preserves the original vector data for opening in Omniball. Mac, Linux, and iPhone Bluetooth companions are not included.

For Android-to-Android: pair both phones in system settings. On one phone choose Connect → Receive from Android. On the other choose its name under Choose paired device. Each phone can send files/boards and stream its drawing. Incoming drawing previews remain separate from the local board until explicitly opened.

Bluetooth radios, pairing, latency, disconnect/reconnect, and real file transfers still need physical-device validation. A browser simulation or emulator cannot establish that evidence.

## Existing Wi-Fi pairing

Connect → Open laptop pairing accepts the token-protected LAN link generated by the existing desktop app. Both devices need the same Wi-Fi or hotspot. This opens the existing desktop companion in the system browser. It is separate from the new Bluetooth companion and local mobile boards.

## Accessibility device checks

Automated WCAG scans are in `verification/accessibility.json`. Before release, also test:

- TalkBack reading order, labels, opening/closing dialogs, note editing, and PDF page text.
- Android large font sizes, display scaling, portrait/landscape, and a screen with a navigation/gesture bar.
- External keyboard navigation and Android Back, including after a PDF picker, the print sheet, or a permission prompt.
- Reduced motion and contrast in real lighting. Drawing itself remains a visual interaction; Notes provides a text-based alternative.

## Developer rebuild

Node.js 24 or newer, JDK 21, Android SDK 36, and Android build tools are required.

```powershell
npm ci
npm run build
npx cap update android
node scripts/sync-assets.mjs
npm test
npm run test:ui
cd android
.\gradlew.bat :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

The browser test uses the installed Windows Chrome by default; set `CHROME_PATH` when it is elsewhere. Companion tests use Python 3.11+ (`PYTHON_PATH` can specify an executable).

Source companion alternative: `python companion/receiver.py`. Run its tests with `python -m unittest discover -s companion -p "test_*.py"`. `--demo` starts its local viewer without Bluetooth. Local viewer requests require a random session token, and the HTTP server binds only to loopback.

Preview billing uses a different Android package from the production app. Real Play purchases must be tested with the production package through Play’s internal test track and the owner’s configured products.
